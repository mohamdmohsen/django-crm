# Django CRM

A simple CRM (Customer Relationship Management) app built with Django and PostgreSQL. 
Lets you manage customer/contact records — add, view, edit, and delete them — behind 
user authentication .

## Features

- User sign up / login / logout
- Add, view, edit, and delete customer records
- Success and error messages (e.g. login, logout, adding a customer, deleting a customer, form validation errors)
- PostgreSQL as the database backend
- Built with Django's admin and ORM

## Tech stack

- Python / Django
- PostgreSQL
- bootstrap
